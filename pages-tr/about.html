Bilişim Sistemleri Mühendisi | Yazılım Geliştirici

Yazılım geliştirme alanında yaklaşık 20 yıllık deneyime sahip, teknolojiye ve sürekli öğrenmeye önem veren bir Bilişim Sistemleri Mühendisiyim. Farklı programlama dilleri ve teknolojilerle edindiğim deneyimi modern yazılım geliştirme yaklaşımlarıyla birleştirerek kendimi geliştirmeye devam ediyorum.

Eğitim Yolculuğum

Yazılım ve bilgisayar teknolojilerine olan ilgim ortaokul yıllarında başladı. Babamla birlikte gittiğim bir banka şubesinde, banka personelinin bilgisayar üzerinden gerçekleştirdiği işlemlerin arka planında neler olduğunu merak etmem, yazılım dünyasına yönelmemdeki ilk adım oldu.

Bu merakımı mesleki bir hedefe dönüştürerek lise eğitimimde Bilgisayar Programcılığı bölümünü tercih ettim. Ön lisans eğitimimi de aynı alanda sürdürdüm. Mühendislik eğitimi alma hedefim doğrultusunda Dikey Geçiş Sınavı (DGS) ile lisans eğitimine geçiş yaparak Bilişim Sistemleri Mühendisliği bölümünden mezun oldum.

Eğitim hayatım boyunca edindiğim teorik bilgileri uygulamalı projelerle desteklemeye ve yazılım geliştirme alanında kendimi sürekli geliştirmeye önem verdim.

Yazılım Geliştirme Deneyimim

Farklı eğitim seviyelerinde ve sonrasında çeşitli programlama dilleriyle otomasyon, masaüstü ve web uygulamaları geliştirdim.

Lise Eğitimi – Bilgisayar Programcılığı

Programlama temellerini öğrendiğim bu dönemde:
  • Pascal
  • Q-Basic
programlama dillerini kullanarak çeşitli otomasyon uygulamaları geliştirdim.

Önlisans Eğitimi – Bilgisayar Programcılığı

Programlama ve uygulama geliştirme konusundaki bilgilerimi ilerleterek:
  • Delphi
  • Visual Basic
teknolojileriyle otomasyon projeleri geliştirdim.

Ayrıca Microsoft Access kullanarak bir kütüphane otomasyon uygulaması hazırladım.

Lisans Eğitimi – Bilişim Sistemleri Mühendisliği

Mühendislik eğitimim sırasında farklı yazılım teknolojileriyle çalışarak:
  • C# dili ile kütüphane uygulaması,
  • Yaş ve cinsiyete göre içerik filtreleme özelliklerine sahip YouTube benzeri bir web uygulaması geliştirdim.

Bu süreçte yazılım geliştirme, uygulama mantığı oluşturma ve problem çözme konularındaki bilgi birikimimi geliştirdim.

Lisans Sonrası Teknolojik Gelişimim

Lisans eğitimimin ardından farklı programlama dilleri ve teknolojiler üzerine eğitimler alarak yazılım geliştirme alanındaki deneyimimi genişlettim.

Java

Java programlama diliyle araç kiralama otomasyonu geliştirdim. Bu çalışma sayesinde nesne yönelimli programlama ve uygulama geliştirme konularındaki deneyimimi ilerlettim.

JavaScript & Web Teknolojileri

JavaScript üzerine aldığım eğitimlerle modern web geliştirme alanına yöneldim.

Bu süreçte:

  • HTML ve CSS kullanarak web arayüzleri geliştirdim.
  • JavaScript ile dinamik ve etkileşimli uygulamalar hazırladım.
  • Node.js kullanarak film sitesi projesi geliştirdim,
  • React ile bileşen tabanlı ve dinamik web uygulamaları oluşturdum.
  • Next.js kullanarak SEO odaklı web projeleri geliştirdim.

Front-End Gelişim Sürecim

Modern web teknolojileri alanındaki yetkinliklerimi güçlendirmek amacıyla HTML, CSS, Bootstrap ve JavaScript eğitimleri aldım ve öğrendiklerimi uygulamalı projelerle pekiştirdim.

Front-End alanında daha profesyonel bir gelişim hedefiyle 05.08.2025 tarihinde Front-End Okulu platformunda eğitim almaya başladım.

Bu süreçte özellikle React ve JavaScript teknolojilerine odaklanarak component tabanlı mimari, React Hooks, API entegrasyonu, veri yönetimi ve responsive web tasarımı konularında çalışmalar gerçekleştirdim.

Öğrendiklerimi gerçek kullanım senaryolarına dayanan projelere dönüştürerek teknik bilgi birikimimi geliştirmeye devam ediyorum.

Kariyer Hedefim

Yazılım geliştirmeyi yalnızca kod yazmaktan ibaret görmüyor; ihtiyaçları analiz etmeyi, problemlere sürdürülebilir çözümler üretmeyi ve kullanıcı deneyimini iyileştirmeyi önemsiyorum.

Yaklaşık 20 yıllık yazılım geliştirme deneyimimi modern Front-End teknolojileriyle birleştirerek kullanıcı odaklı, işlevsel ve sürdürülebilir uygulamalar geliştirmeyi hedefliyorum.

Teknik araştırma, analitik düşünme ve sürekli öğrenme yaklaşımıyla yazılım projelerine katkı sağlayabileceğim, bilgi ve deneyimimi geliştirebileceğim profesyonel iş birliklerine açığım.
