Dursun Köktürk

Bilişim Sistemleri Mühendisi | Yazılım Geliştirici

Bilişim Sistemleri Mühendisliği altyapısına ve freelance çalışmalar ile bireysel projeler kapsamında edindiğim yaklaşık 20 yıllık yazılım geliştirme deneyimine sahip bir Yazılım Geliştiricisiyim. Back-End alanındaki teknik birikimimi modern Front-End teknolojileriyle birleştirerek React ve JavaScript kullanarak kullanıcı odaklı, işlevsel ve sürdürülebilir web uygulamaları geliştiriyorum. Teknik araştırmaya, problem çözmeye ve sürekli öğrenmeye önem vererek yazılım geliştirme alanındaki yetkinliklerimi geliştirmeye devam ediyorum.

Eğitim Yolculuğum

Yazılım ve bilgisayar teknolojilerine olan ilgim ortaokul yıllarında başladı. Babamla birlikte gittiğim bir banka şubesinde, banka personelinin bilgisayar üzerinden gerçekleştirdiği işlemlerin arka planında neler olduğunu merak etmem, yazılım dünyasına yönelmemdeki ilk adım oldu.

Bu merakımı mesleki bir hedefe dönüştürerek lise eğitimimde Bilgisayar Programcılığı bölümünü tercih ettim. Ön lisans eğitimimi de aynı alanda sürdürdüm. Mühendislik eğitimi alma hedefim doğrultusunda Dikey Geçiş Sınavı (DGS) ile lisans eğitimine geçiş yaparak Bilişim Sistemleri Mühendisliği bölümünden mezun oldum.

Eğitim hayatım boyunca edindiğim teorik bilgileri uygulamalı projelerle desteklemeye ve yazılım geliştirme alanında kendimi sürekli geliştirmeye önem verdim.

Yazılım Geliştirme Deneyimim

Yaklaşık 20 yıldır freelance ve bireysel çalışmalar kapsamında yazılım geliştirme projeleri üzerinde çalışıyorum. Bu sürecin 15 yılını Back-End, 5 yılını ise Front-End alanındaki çalışmalarım oluşturuyor. Farklı programlama dilleri ve teknolojiler kullanarak otomasyon, masaüstü ve web tabanlı uygulamalar geliştirdim. Bu çalışmalar sayesinde yazılım geliştirme süreçlerine bütünsel yaklaşma ve teknik problemleri farklı açılardan değerlendirme becerisi kazandım. Güncel çalışmalarımda ise bu birikimimi React ve JavaScript başta olmak üzere modern Front-End teknolojileriyle birleştiriyorum.

2025 – Günümüz | Front-End Gelişim Sürecim

Modern Front-End teknolojilerindeki yetkinliklerimi geliştirmek amacıyla HTML, CSS, Bootstrap ve JavaScript eğitimleri aldım. Öğrendiklerimi uygulamalı projelerle pekiştirerek web arayüzleri ve etkileşimli uygulamalar geliştirdim.

Front-End alanındaki bilgi ve becerilerimi daha ileri taşımak amacıyla 05.08.2025 tarihinde Front-End Okulu platformunda eğitim almaya başladım.

Bu süreçte özellikle React ve JavaScript üzerine yoğunlaşarak component tabanlı mimari, React Hooks, REST API entegrasyonu, veri yönetimi ve responsive web tasarımı konularında çalışmalar gerçekleştirdim.

Teknolojiler ve Yetkinlikler

  • JavaScript (ES6+) ve React
  • HTML5 ve CSS3
  • React Hooks ve Component Tabanlı Mimari
  • REST API Entegrasyonu
  • Fetch API ve Asenkron JavaScript (async/await)
  • Duyarlı Web Tasarımı

Edindiğim bilgileri gerçek kullanım senaryolarına dayanan projelerde uygulayarak teknik yetkinliklerimi geliştirmeye devam ediyorum.
